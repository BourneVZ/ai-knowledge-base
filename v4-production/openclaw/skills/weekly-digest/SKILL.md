# 近期内容速览

## 触发词

- 本周 / 这周看到了啥
- 最近 7 天 / 最近 N 天
- 最近有什么新的

## 做法

1. Read `knowledge/articles/index.json`（索引按 `collected_at` 降序，新的在前）
2. 定日期范围：
   - 默认"最近 7 天" = 今天往前 7 天
   - 说"本周 / 这周" = 本周一 00:00 至今
   - 用户给了 N 就用最近 N 天
3. 按 `collected_at` 过滤出范围内的条目
4. 回复格式（先总数后列表，Telegram 纯文本，不用表格；按时间降序）：

   最近 7 天共收录 N 篇：

   1. <title>（<category> · 创新分 4）
   2. ...

   超过 10 篇只列最新的 10 篇，结尾注明"共 N 篇，以上为最新的 10 篇"。
5. 用户要某篇详情时，再用 `file` 字段拼路径 Read `knowledge/articles/<file>`（一次 ≤ 5 篇）。

## 空结果（重要）

采集是定时批处理，知识库经常不是实时的——"最近 7 天"筛出 0 条是正常情况，按下面回：

- 如实说"最近 7 天没有新收录"
- 必须附索引第一条（最新一条）的 `collected_at`，说明知识库目前覆盖到哪天
- 可以问一句要不要改看"最新收录的 7 篇"，用户确认后再给，不要自作主张换范围

## 禁止

- 别 read 目录（EISDIR）——只 read index.json，按需再读具体文章文件
- 别在空结果时拿旧数据冒充"最近 7 天"
- 别用表格
